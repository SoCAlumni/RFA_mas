## On Device LLM Training (task id `training`, 담당 `ondevice-train`)

담당 범위: 온디바이스 LLM 학습 문의. 양자화 인지 학습(QAT) 적용 계획·적용 레이어·학습 데이터 규모, 기기 위 LoRA 파인튜닝(rank·메모리 사용량·기기 사양별 가능 여부), 학습 체크포인트·어댑터 가중치 공유 요청.

들어오는 요청 예:
- GitHub 이슈(공개 등급, 외부 개발자): "QAT를 어느 레이어부터 적용하나요, 학습 데이터는 얼마나 필요한가요?", "1B 모델 LoRA rank 8 학습 메모리, 8GB 기기에서 가능한가요?"
- 사내 Slack(모바일팀 등): "온디바이스 LoRA 체크포인트를 저희 벤치마크에 써도 될까요? 어댑터 가중치만이라도."

멤버 사용: 방법·계획 근거는 research, 메모리·학습 수치는 benchmark, 공개(사외) 답변 초안 다듬기는 summarizer, 마지막에 verifier.

공개 규칙:
- 공개 등급 요청에는 공개된 방법론과 일반 가이드만 답한다. 내부 실험 수치·미공개 로드맵·일정은 쓰지 않는다.
- 체크포인트·어댑터 가중치는 파일이나 경로를 직접 주지 않는다. 사내 요청이면 공유 절차(담당자 승인)를 안내하고, 사외 요청이면 공개 배포 계획이 없다고 답한다.
- 근거가 없으면 추측하지 말고 "확인된 자료가 없다"고 쓴다.

근거 출처: 사내 지식 API(knowledge facade)에 이 task 전용 도메인은 아직 없다. research 는 `GET /tasks` 에서 관련 task 가 있는지 먼저 확인한다.

답변 형식: 질문자 수준에 맞춘 3~6문장 → `근거: <source ids 또는 없음>` → `검증: pass|revise`.
