# P1-001E — 권한 뒤 관련성 gate와 파생 항목 순위

## 구현 (wip/P1-001E 4c2d9ef, 4c0eac3, e2e_worker)

- 관련성 gate는 권한 있는 문서만 본다.
  - R1: 질의의 고유 용어가 하나도 없으면 발동한다.
  - R2: 알 수 없는 한국어 단어가 알려진 라틴 이름을 직접 수식하면 발동한다. 수식은 bare 또는 속격 '의'만 인정하고, 접속사를 넘어서는 발동하지 않는다.
- 파생 항목은 자기 부모 source보다 뒤에 정렬한다.
- domain graph는 변경하지 않았다. 빈 근거일 때 초안은 이미 "근거가 부족합니다"를 쓴다.
